GizlilikPrivacy

Son güncelleme: 24 Eylül 2026. Tanıtım sitesi ve uygulama birbirinden ayrı veri sınırlarına sahiptir.Updated 24 September 2026. The website and desktop application have separate data boundaries.

Tanıtım sitesiProduct website

ss.isolmaz.com indirme ve rehber içindir; görüntü yükleme hesabı değildir. Bu statik site uygulama içi hesap veya izleme çerezi içermez. Ağ sağlayıcıları sitenin çalışması için IP ve erişim zamanı gibi teknik bağlantı verilerini işleyebilir.ss.isolmaz.com serves downloads and documentation, not image hosting. The static site does not provide app accounts or tracking cookies. Network providers may process technical connection data such as IP address and request time.

İndirme düğmesi sizi GitHub Releases'e götürür; GitHub'ın kendi gizlilik koşulları uygulanır.Download buttons lead to GitHub Releases, where GitHub's own privacy terms apply.

Yerel uygulamaLocal application

Yakalama, çizim, panoya kopyalama ve yerel kayıt bilgisayarınızda yapılır. İlk Yükle Cloudflare bağlantısını açar; görüntü yalnızca kendi hesabınızda yeni Worker kurulup bağlandığında gönderilir. Genel ayarlar %APPDATA%\isolmaSS\settings.json dosyasındadır. Ayrı yükleme/yönetim anahtarları ve isteğe bağlı varsayılan resim şifresi %LOCALAPPDATA%\isolmaSS\cloud-credentials.bin dosyasında Windows kullanıcı hesabına bağlı DPAPI ile korunur. Cloudflare OAuth erişim anahtarı kurulum sırasında bellektedir; dosyaya yazılmaz.Capture, drawing, copying and saving run locally. First Upload opens Cloudflare connection; the image is sent only after a new Worker is installed and connected in your account. General settings live in %APPDATA%\isolmaSS\settings.json. Separate upload/admin keys and an optional image password are protected with per-user Windows DPAPI in %LOCALAPPDATA%\isolmaSS\cloud-credentials.bin. The Cloudflare OAuth access token remains in memory during setup and is not written to disk.

İsteğe bağlı paylaşımOptional sharing

Görüntü baytları, linkler, süreler, sayaçlar ve şifre doğrulama bilgileri seçtiğiniz Cloudflare hesabının özel SQLite Durable Object alanındadır. Şifrenin kendisi yerine her görüntüye özel tuzlu doğrulama değeri saklanır. Uygulama ayrı IP/ziyaretçi profili tutmaz; Cloudflare ağ kayıtları hesabınızın ayarlarına bağlıdır. Bu tanıtım sitesi görüntü veya OAuth anahtarı barındırmaz.Image bytes, links, expiry, counters and password verifiers stay in a private SQLite Durable Object in your selected Cloudflare account. Images store salted password verifiers, never the password itself. The app does not build visitor/IP profiles; Cloudflare network logs depend on your account settings. This product site hosts no images or OAuth tokens.

Şifresiz linki bilen kişiler görüntüyü açıp kaydedebilir. Bağlantıyı silmek yeni erişimi kapatır ama daha önce indirilmiş kopyaları silmez. Yerel bağlantıyı kaldırmak buluttaki Worker ve resimleri silmez.Anyone with an unprotected link can view and save it. Deletion closes new access but cannot erase previously downloaded copies. Disconnecting locally leaves the remote Worker and images intact.

Güvenlik bildirimiSecurity contact

Gizlilik ve güvenlik bildirimi için güvenlik politikasını kullanın. Gizli anahtar, görüntü veya kişisel veri içeren bir herkese açık issue açmayın.Use the security policy for privacy or vulnerability reports. Do not post tokens, captures or personal data in public issues.
