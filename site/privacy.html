GizlilikPrivacy

Son güncelleme: 24 Eylül 2026. Tanıtım sitesi ve uygulama birbirinden ayrı veri sınırlarına sahiptir.Updated 24 September 2026. The website and desktop application have separate data boundaries.

Tanıtım sitesiProduct website

ss.isolmaz.com indirme ve rehber içindir; görüntü yükleme hesabı değildir. Bu statik site uygulama içi hesap veya izleme çerezi içermez. Ağ sağlayıcıları sitenin çalışması için IP ve erişim zamanı gibi teknik bağlantı verilerini işleyebilir.ss.isolmaz.com serves downloads and documentation, not image hosting. The static site does not provide app accounts or tracking cookies. Network providers may process technical connection data such as IP address and request time.

İndirme düğmesi sizi GitHub Releases'e götürür; GitHub'ın kendi gizlilik koşulları uygulanır.Download buttons lead to GitHub Releases, where GitHub's own privacy terms apply.

Yerel uygulamaLocal application

Yakalama, çizim, panoya kopyalama ve yerel kayıt bilgisayarınızda yapılır. İlk Yükle kurulumu açar; görüntü ancak kendi Worker'ınızla eşleştirme başarılı olunca gönderilir. Genel ayarlar %APPDATA%\isolmaSS\settings.json içindedir. Cloudflare anahtarları ve isteğe bağlı varsayılan resim şifresi, Windows kullanıcı hesabına bağlı DPAPI ile ayrı bir dosyada korunur. Yarım kalmış kurulumun iki anahtarı da %LOCALAPPDATA%\isolmaSS\cloud-setup.bin dosyasında DPAPI ile korunur ve eşleşince temizlenmeye çalışılır.Capture, drawing, copying and saving run on your computer. The first Upload opens setup; the image is sent only after pairing your own Worker succeeds. General settings are in %APPDATA%\isolmaSS\settings.json. Cloudflare tokens and an optional default image password live in a separate file protected by per-user Windows DPAPI. Keys for an unfinished setup are also protected in %LOCALAPPDATA%\isolmaSS\cloud-setup.bin and removed after pairing when file access permits.

İsteğe bağlı paylaşımOptional sharing

Yüklenen dosya kendi Cloudflare hesabınızın özel R2 deposundadır; link, son kullanma, sayaç ve şifre doğrulama verisi hesabınızdaki D1'de tutulur. Şifrenin kendisi değil, her resme özel tuzlu doğrulama değeri saklanır. Uygulama ayrı IP/ziyaretçi profili tutmaz; Cloudflare'ın ağ ve gözlem kayıtları kurulum sahibinin ayarlarına bağlıdır.Uploaded bytes live in your account's private R2 bucket. Links, expiry, counters and password verification data live in your D1. Each image stores a salted verifier, not the password itself. The app does not build visitor/IP profiles; Cloudflare's network and observability logs depend on the account owner's configuration.

Şifresiz linki bilen kişiler görüntüyü açıp kaydedebilir. Bağlantıyı silmek yeni erişimi kapatır ama daha önce indirilmiş kopyaları silmez. Bulut hesabını ve içeriği sahibi yönetir.Anyone with an unprotected link can open and save it. Deleting the link closes new access but cannot erase previously downloaded copies. The account owner controls stored content.

Güvenlik bildirimiSecurity contact

Gizlilik ve güvenlik bildirimi için güvenlik politikasını kullanın. Gizli anahtar, görüntü veya kişisel veri içeren bir herkese açık issue açmayın.Use the security policy for privacy or vulnerability reports. Do not post tokens, captures or personal data in public issues.
