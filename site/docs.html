KullanımUsage

GereksinimlerRequirements

  • Windows 10 veya Windows 11, 64 bit. Yerel ekran görüntüsü için hesap gerekmez.Windows 10 or 11, 64-bit. Local screenshots need no account.
  • Paylaşım için kendi Cloudflare hesabınız ve bu hesapta Workers ile SQLite Durable Objects kullanma yetkisi gerekir. GitHub hesabı, R2 veya D1 aboneliği gerekmez. Cloudflare hesap kısıtları ve fatura koşulları ayrıca geçerlidir.Sharing needs your own Cloudflare account with Workers and SQLite Durable Objects access. No GitHub account or R2/D1 subscription is needed. Cloudflare account restrictions and billing terms still apply.

Yerel kullanımLocal capture

  1. İmzalı Windows sürümünü indirin ve kurun. Taşınabilir ZIP de GitHub Releases üzerinde bulunur.Download the signed Windows release and install it. A portable ZIP is available on GitHub Releases.
  2. PrintScreen'e basın veya tepsi menüsünden yakalayın. Bölgeyi seçin, düzenleyin; Ctrl+C panoya, Ctrl+S dosyaya kaydeder.Press PrintScreen or capture from the tray. Select a region and edit; Ctrl+C copies and Ctrl+S saves.
  3. Opak Karart hassas pikselleri kapatır. Bulanıklaştırma güvenli sansür değildir.Opaque Redact covers sensitive pixels. Blur is not secure redaction.

Cloudflare kurulumuCloudflare setup

  1. Bir görüntü seçip Yükle'ye basın. İlk seferde resim gönderilmez; bağlantı penceresi açılır.Select a screenshot and click Upload. First use opens connection setup without sending the image.
  2. Cloudflare ile devam et'e basın. Açılan tarayıcıda kendi Cloudflare hesabınızla giriş yapın, Workers Scripts Write ve Memberships Read izinlerini onaylayın. Birden fazla hesap varsa uygulamada kurulacak hesabı seçin.Choose Continue with Cloudflare. Sign in to your own Cloudflare account in the browser and approve Workers Scripts Write and Memberships Read. If you have multiple accounts, select the destination in the app.
  3. Uygulama yalnız seçilen hesapta yeni rastgele adlı Worker ve SQLite Durable Object oluşturur, workers.dev adresini bağlar ve anahtarları Windows DPAPI ile korur. GitHub, alan adı veya anahtar yapıştırma adımı yoktur.The app creates a new, randomly named Worker and SQLite Durable Object only in the chosen account, connects its workers.dev address and protects Worker keys with Windows DPAPI. No GitHub account, domain or key pasting is needed.
  4. Kurulum başarılı olunca bekleyen görüntü yüklenir ve bağlantı panoya kopyalanır. Vazgeçerseniz görüntü yerelde kalır; başarısız yüklemede pano değişmez. Sonraki Yükle işlemleri yeniden Cloudflare girişi istemez.After successful setup, the pending image uploads and its link is copied. Canceling leaves the image local; failed uploads do not change the clipboard. Later uploads do not need another Cloudflare login.

Cloudflare OAuth erişim anahtarı yalnız kurulum belleğinde tutulur; site hesabınıza giriş yapmaz veya görüntüleri barındırmaz. Tarayıcı sekmesi otomatik kapanmazsa kapatıp uygulamaya dönün. Yerel bağlantıyı kaldırmak Cloudflare'daki Worker'ı veya resimleri silmez.The Cloudflare OAuth access token stays in memory only during setup; this website does not log in to your account or host images. If the browser cannot close its tab automatically, close it and return to the app. Disconnecting locally does not delete the remote Worker or images.

Ayarlar ve istatistiklerSettings and statistics

Son tutulan resim sayısı (başlangıç 50), günlük yükleme/görüntüleme, görüntü ve toplam depolama boyutu, saklama süresi ile uyarı yüzdesi ayarlanır. Sınırda uyarma, yeni yüklemeleri veya görüntülemeyi durdurma seçenekleri vardır.Set retained images (initially 50), daily uploads/views, image and total storage sizes, retention and warning percentage. At the threshold, warn or stop uploads or views.

Günlük/aylık sayaçlar ve aktif depolama yalnız bu Worker içindir; Cloudflare hesabının tamamını göstermez. Listedeki resimler silinebilir; isteğe bağlı resim şifresi sonraki yüklemelere uygulanır.Daily/monthly counters and active storage cover this Worker only, not the full Cloudflare account. Delete individual images; an optional image password applies to future uploads.

Free sınırlarıFree-tier limits

Workers ve SQLite Durable Objects ücretsiz kullanım payları Cloudflare hesabının tamamıyla paylaşılır. Uygulama, tek Durable Object için en fazla 800 MB aktif görüntü ve görüntü başına en fazla 10 MB ayarlar; tek BLOB 1 MB parçalara bölünür. Bu sınırlar Cloudflare hesabının genel faturasını veya başka projelerin kullanımını izleyemez.Workers and SQLite Durable Objects free allowances are shared across the entire Cloudflare account. This app limits active images to 800 MB in one Durable Object and each image to 10 MB; individual BLOBs are split into 1 MB chunks. These limits cannot track other projects or guarantee the account-wide bill.

Güncel kotaları ve olası ücretleri Workers sınırları, Durable Objects sınırları ve Cloudflare fatura panelinden kontrol edin. Ücretsiz veya sıfır fatura garantisi verilmez.Check current Workers limits, Durable Objects limits and your Cloudflare billing dashboard. No unlimited-free or zero-bill promise is made.

GüvenlikSecurity

Linkler 192 bit rastgeledir; görüntü ve kayıtlar hesabınızdaki özel Durable Object içinde tutulur. Şifresiz geçerli linki bilen herkes resmi açabilir. İsteğe bağlı şifreyi linkten ayrı paylaşın. Silinen link erişilemez; önceden kaydedilmiş kopyalar geri alınamaz. Gizlilik ve güvenlik politikası.Links have random 192-bit IDs; images and records stay in a private Durable Object in your account. Anyone with a valid unprotected link can view it. Share optional passwords separately. Deletion closes the link but cannot revoke past downloads. See Privacy and the security policy.

Sorun gidermeTroubleshooting

  • İlk Yükle kurulum açıyor: Worker henüz bağlanmamıştır; izin ve kurulum bitmeden görüntü gönderilmez.First Upload opens setup: No Worker is connected; the image stays local until authorization and installation finish.
  • Tarayıcı açılmadı/izin verilmedi: Cloudflare bağlantısını uygulamada yeniden başlatın; 127.0.0.1:38481 dönüş portunun kullanılabilir olduğundan emin olun. İzniniz olmadan kurulum yapılmaz.Browser or consent failed: Start Cloudflare connection again in the app and ensure loopback port 127.0.0.1:38481 is free. Setup never continues without consent.
  • 401: Worker sırrı yerel bağlantıyla uyuşmuyor; yeni bağlantı kurulması gerekebilir. Yerel bağlantıyı kaldırmak eski Worker/resimleri silmez.401: The Worker's secret does not match the local connection; you may need a new installation. Disconnecting locally leaves the old Worker/images intact.
  • 429/507: Günlük kota veya aktif depolama sınırı dolmuştur. UTC sıfırlanmasını bekleyin, sınırı ayarlayın veya eski resimleri silin.429/507: Daily or storage limit reached. Wait for the UTC reset, change the limit or delete old images.
  • 404: Resim silinmiş, süresi dolmuş veya adres yanlıştır.404: The image was deleted, expired or the address is wrong.
